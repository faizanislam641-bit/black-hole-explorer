# 🌌 Black Hole Explorer

An interactive 2D space gravity simulator built with pure HTML, CSS, and JavaScript.

## 🚀 Features
- Real-time 2D gravity simulation
- Supermassive black hole with event horizon & accretion disk
- 12+ named planets with orbits, moons, and rings
- Drop astronauts, rockets, asteroids into the black hole
- Spaghettification effect (real stretching physics)
- Zoom (0.15x to 8x), pan, inspect objects
- Works on mobile + desktop

## 🎮 Controls
- **Drag** → Pan camera
- **Scroll / Pinch** → Zoom
- **Click object** → See physics info
- **Spawn buttons** → Drop objects
